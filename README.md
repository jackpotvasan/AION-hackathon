# ProcureX

ProcureX is an AI-powered, cyber-secure procurement decision-intelligence platform built on an integrated procurement ERP foundation.

## Current Phase

**Phase 16: Testing and Hardening**

The project is intentionally being developed in gated phases. Phase 1 is documented in [docs/phase-1-foundation.md](docs/phase-1-foundation.md), Phase 2 in [docs/phase-2-system-design.md](docs/phase-2-system-design.md), Phase 3 in [docs/phase-3-development-environment.md](docs/phase-3-development-environment.md), Phase 4 in [docs/phase-4-backend-foundation.md](docs/phase-4-backend-foundation.md), Phase 5 in [docs/phase-5-auth-rbac.md](docs/phase-5-auth-rbac.md), Phase 6 in [docs/phase-6-core-procurement-mvp.md](docs/phase-6-core-procurement-mvp.md), Phase 7 in [docs/phase-7-secure-document-processing.md](docs/phase-7-secure-document-processing.md), Phase 8 in [docs/phase-8-ai-quote-intelligence.md](docs/phase-8-ai-quote-intelligence.md), Phase 9 in [docs/phase-9-quote-normalization.md](docs/phase-9-quote-normalization.md), Phase 10 in [docs/phase-10-true-cost-engine.md](docs/phase-10-true-cost-engine.md), Phase 11 in [docs/phase-11-vendor-comparison.md](docs/phase-11-vendor-comparison.md), Phase 12 in [docs/phase-12-approval-workflow.md](docs/phase-12-approval-workflow.md), Phase 13 in [docs/phase-13-purchase-orders.md](docs/phase-13-purchase-orders.md), Phase 14 in [docs/phase-14-inventory-goods-receipt.md](docs/phase-14-inventory-goods-receipt.md), Phase 15 in [docs/phase-15-finance-invoice-matching.md](docs/phase-15-finance-invoice-matching.md), and the current hardening work in [docs/phase-16-testing-hardening.md](docs/phase-16-testing-hardening.md).

## Guiding Principle

**AI RECOMMENDS -> HUMAN APPROVES -> SYSTEM EXECUTES.**

Lowest price is not assumed to be the best decision: ProcureX evaluates true cost, vendor performance, and business and cybersecurity risk.

## Roadmap

1. Project Foundation
2. System Design
3. Development Environment
4. Backend Foundation
5. Auth and RBAC
6. Core Procurement MVP
7. Secure Document Processing
8. AI Quote Intelligence
9. Quote Normalization
10. True Cost, comparison, recommendation, and approval workflow

Advanced intelligence, inventory, finance, prediction, simulation, and deployment follow only after the MVP workflow is verified end to end.
